## Featured Projects

<details open>
<summary><b>Region-Adaptive Super-Resolution for Urban Satellite Imagery</b></summary>

<br/>

Task-guided super-resolution framework that allocates compute per region. A Region Importance Network (RIN) predicts per-pixel importance, and an Adaptive SR Generator routes important regions such as buildings and roads through a heavier branch.

| | |
|:--|:--|
| **Stack** | Python, PyTorch, ResNet-50 / ResNet-152 segmenters, Lion / AdamW, FastAPI |
| **Scale** | LoveDA dataset: 2,522 train pairs, 1,669 validation pairs, 8 land-cover classes |
| **Performance** | 31.27 dB PSNR, 0.8273 SSIM, 38.4% mIoU vs 22.0% for bicubic upscaling |
| **Security** | Local inference service with a validated REST interface |
| **Impact** | Building IoU 52.10% and Road IoU 48.65%, with the largest gains on high-importance classes |
| **Repository** | [Region-Adaptive-Super-Resolution-for-Urban-Satellite-Imagery](https://github.com/VAMSI-KRISHNA-N/Region-Adaptive-Super-Resolution-for-Urban-Satellite-Imagery) |

Combines a learned importance map, region-wise routing and a frozen-segmenter task loss, a combination that remains an open gap in recent super-resolution surveys. Includes a full ablation study, an IEEE-style paper blueprint and a FastAPI inference service.

</details>

<summary><b>DeepHealthX: Multi-Modal Explainable Deep Learning for Cardiac Disease Detection</b></summary>

<br/>

Tri-modal deep learning system that fuses clinical data, ECG signals and cardiac MRI to predict cardiovascular disease with clinician-interpretable explanations.

| | |
|:--|:--|
| **Stack** | Python, TensorFlow, MobileNetV2, 1D-CNN, DNN, SHAP, Grad-CAM |
| **Scale** | Three modalities: tabular clinical features, ECG time series, MRI images |
| **Performance** | Stage-2 fusion head combining modality-specific encoders |
| **Security** | Research prototype on de-identified public data |
| **Impact** | Interpretable predictions through SHAP, saliency maps and Grad-CAM |
| **Repository** | [View on GitHub](https://github.com/VAMSI-KRISHNA-N?tab=repositories) |

A DNN handles clinical features, a 1D-CNN handles ECG arrhythmia patterns and a transfer-learning MobileNetV2 handles MRI. The explainability work led to the **CA-HXAI** research paper on XAI surrogate optimization.

</details>
